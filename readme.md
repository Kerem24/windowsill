# Windowsill

A small blog layout about growing herbs and salad greens in a flat, on a balcony or in a room with one decent window.

I built this while working through [The Odin Project](https://www.theodinproject.com/). It is practice for HTML, CSS and a little JavaScript, so it is not perfect.

## What's in it

- Home page with a hero section, a list of latest posts, an about section and a topic list
- Email signup page with simple form validation (front end only, nothing is sent anywhere)
- Footer year filled in with JavaScript
## Built with

HTML, CSS, JavaScript. No frameworks, no build step.

## Run it

Clone the repo and open `index.html` in your browser.

```
git clone https://github.com/Kerem24/windowsill.git
```

## What I practiced

- Flexbox layouts
- Media queries
- Styling forms and form validation with CSS
- Selecting elements and adding event listeners with JavaScript
- There is no advanced backend since I didn't learn yet. Just the front-end
